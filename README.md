# 🚀 CareerCraft  
## AI-Powered Career Intelligence & Skill Gap Analysis Platform

![CareerCraft Banner](https://img.shields.io/badge/Project-CareerCraft-blue)
![Status](https://img.shields.io/badge/Status-In%20Development-orange)
![Tech Stack](https://img.shields.io/badge/Stack-MERN%20%7C%20Flask%20%7C%20AI-green)

CareerCraft is an **AI-powered career guidance platform** designed to help students, freshers, and professionals identify career opportunities, analyze skill gaps, and build personalized learning roadmaps.

The platform uses **Artificial Intelligence, Natural Language Processing (NLP), and Data-Driven Recommendations** to compare user skills with industry requirements and provide actionable career growth paths.

---

# 📌 Problem Statement

Many students and job seekers struggle with:

- Understanding which career path matches their skills
- Identifying missing skills required for their dream role
- Finding structured learning resources
- Building ATS-friendly resumes
- Tracking their career preparation progress

CareerCraft solves these challenges by providing an intelligent career ecosystem.

# ✨ Key Features

## 👤 User Module

- User Registration & Login
- Secure authentication using JWT
- Profile management
- Career preference selection


## 📄 Resume Intelligence Module

- Upload PDF resumes
- Extract resume text
- Identify technical and soft skills
- Generate skill profile using NLP


## 🎯 Career Recommendation Engine

- Compare user skills with career requirements
- Calculate career match percentage
- Suggest suitable career roles
- Recommend alternative career paths


## 🔍 Skill Gap Analysis

Identifies:

- Existing skills
- Missing skills
- Required industry skills
- Learning priorities


Example:

```
Target Career:
Data Scientist

Matched Skills:
Python
SQL
Machine Learning

Missing Skills:
Deep Learning
Statistics
Cloud Platforms
```
